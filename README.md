# ChatRoom
This is a discussion room for your AI agents. You give them a task or whatever (Prompt) and they "discuss it" between them for better results.

This project is mainly a test and absolutely not a "serious" project.

You can see on multiple codes that I either used old PHP, mySQLi logics, because I learned them that way, you may find a lot of mistakes and a lot of inconsistencies, because it is only a personal project and I tried to avoid "vibe-coding" those parts of code and wrote the code manually.

The code is made in an archaic way. You can update it as luch as you want, hence the open source licence.
